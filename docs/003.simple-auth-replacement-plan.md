# Notes9 Simple Authentication System Replacement Plan

> **Objective**: Replace the complex AFFiNE authentication system with a simple email/password authentication system for the air-gapped notes9 app, while preserving all other functionality.

## 📋 **Current State Analysis**

### **What We Have Now**

- ✅ OAuth providers (Google, GitHub, Apple, OIDC) - **ALREADY DISABLED**
- ✅ External telemetry and tracking - **ALREADY REMOVED**
- ✅ Air-gap security implemented - **COMPLETE**
- ❌ Magic link authentication - **NEEDS REMOVAL**
- ❌ Complex multi-step authentication UI - **NEEDS SIMPLIFICATION**
- ❌ Email verification flow - **NEEDS REMOVAL**
- ❌ Connected accounts table - **NEEDS CLEANUP**
- ❌ Complex session management - **NEEDS SIMPLIFICATION**

### **What We're Keeping**

- ✅ PostgreSQL database with existing user table structure
- ✅ Password hashing and validation (`CryptoHelper`)
- ✅ Basic session management (`UserSession`, `Session` tables)
- ✅ User roles and workspace permissions
- ✅ All core AFFiNE functionality (documents, workspaces, etc.)
- ✅ Docker Compose local infrastructure

### **Target Architecture**

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   Login Form    │───▶│   Auth Service  │───▶│   PostgreSQL    │
│ (Email/Password)│    │ (Simplified)    │    │ (Existing DB)   │
└─────────────────┘    └─────────────────┘    └─────────────────┘
        │                        │                        │
        │                        ▼                        │
        │              ┌─────────────────┐                │
        └─────────────▶│ Session Manager │◀───────────────┘
                       │ (Simplified)    │
                       └─────────────────┘
```

## 🚀 **Implementation Plan**

### **Phase 1: Backend Authentication Cleanup**

#### **1.1 Remove OAuth Infrastructure**

- [ ] **Remove OAuth Controllers** (`packages/backend/server/src/plugins/oauth/`)
  - Delete `OAuthController` class
  - Remove OAuth routes from API
  - Remove OAuth provider configurations
- [ ] **Clean Up OAuth Database Tables**
  - Keep `user_connected_accounts` table structure (for data integrity)
  - Remove OAuth-related queries and methods
  - Add migration to clean up any OAuth data
- [ ] **Update Backend Modules**
  - Remove OAuth module from `app.module.ts`
  - Remove OAuth provider registrations
  - Clean up OAuth-related dependencies

#### **1.2 Simplify Authentication Service**

- [ ] **Streamline AuthService** (`packages/backend/server/src/core/auth/service.ts`)
  - Remove magic link authentication methods
  - Remove OAuth sign-in methods
  - Keep only `signIn(email, password)` and `signUp(email, password)`
  - Simplify session management
- [ ] **Update AuthController** (`packages/backend/server/src/core/auth/controller.ts`)
  - Remove `/api/auth/magic-link` endpoint
  - Remove `/api/oauth/callback` endpoint
  - Keep only `/api/auth/sign-in` and `/api/auth/sign-up`
  - Remove email verification requirements
  - Remove captcha requirements

#### **1.3 Simplify User Management**

- [ ] **Update UserModel** (`packages/backend/server/src/models/user.ts`)

### **Phase 3: Database Schema Optimization**

#### **3.1 Create Migration for Cleanup**

- [ ] **Database Migration** (`packages/backend/server/migrations/`)

  ```sql
  -- Remove OAuth connected accounts
  DELETE FROM user_connected_accounts WHERE provider IN ('google', 'github', 'apple', 'oidc');

  -- Auto-verify all existing users
  UPDATE users SET email_verified_at = COALESCE(email_verified_at, created_at) WHERE email_verified_at IS NULL;

  -- Clean up verification tokens
  DELETE FROM verification_tokens WHERE type IN (oauth_related_types);
  ```
